# Rollup / Drill-down

작성: 김예원 · 검증 갱신: 2026-11-23

## 사용

메인의 Rollup / Drill down 메뉴에서 `analysis/rollup.php`로 이동합니다.
기간, 거래 단위, 등급, 소비 도시를 선택해 조회합니다.
과일 계층은 과일군 → 품목 → 품종, 시간 계층은 연도 → 월입니다.
결과 이름을 클릭하면 하위 단계로, 경로나 상위 집계 링크를 클릭하면 상위 단계로 이동합니다.
탐색 링크는 조회 조건을 유지하고, 조건 초기화는 모든 조건을 초기화합니다.
분석 기준을 바꿔도 선택한 과일과 연도 범위는 유지합니다.

## 집계 기준

- 공통 `v_price_weather`만 조회하며 사용자 값은 PDO Prepared Statement로 바인딩합니다.
- 거래 단위와 등급은 필수입니다. 서로 다른 단위·등급을 평균하지 않습니다.
- `GROUP BY ... WITH ROLLUP`으로 현재 단계와 현재 범위 전체를 계산합니다.
- 전체 평균은 하위 평균들의 단순 평균이 아니라 원본 월별 가격 행에서 계산합니다.
- 월평균 가격 행마다 같은 가중치를 부여합니다. 일수·거래량 가중 평균은 아닙니다.
- 최저·최고는 월내 일평균 가격의 최저·최고를 사용합니다.
- 품목·과일군에서 기상 수치를 합산하지 않습니다.

## 근거와 준비 상태

- [DB 구조 및 첨부 SQL](https://app.notion.com/p/81fa47762fc882549a7d0137015a7e8e)
- [가격 정제 기준](https://app.notion.com/p/15da47762fc8829281f9017fa452f34b)

팀의 공통 `sql/dbcreate.sql`, `sql/dbinsert.sql`을 적용한 DB를 사용합니다.
기존 DB 갱신은 `sql/README.md`를 따르며 데이터가 있는 DB에 insert를 반복 실행하지 않습니다.
가격 정제본은 할인 Y만 제외하므로 모두 확인된 비할인 가격으로 해석하지 않습니다.
로컬 검증 DB에는 가격 5,386개, 기상 1,056개가 있습니다. 기상은 total_rain 1,056개,
drought_level 958개가 채워져 있으며 미확보 98개는 NULL입니다.
Rollup은 가격 컬럼만 사용하므로 기상 결측을 0으로 보간하지 않습니다.
이 기능은 DB 스키마나 데이터를 변경하지 않으며 조회에 로그인을 요구하지 않습니다.
팀의 공통 로그인 정책·최종 레이아웃은 통합 시 맞춥니다.

## 검증

```powershell
& C:/xampp/php/php.exe scripts/check-rollup.php
& C:/xampp/php/php.exe scripts/check-rollup.php --db
```

입력·URL 검사와 MariaDB 10.11.16 집계 검사를 통과했습니다.
DB 검사는 연결 전용 임시 테이블만 생성하며 영구 데이터는 변경하지 않습니다.
과일 3단계, 연도/월, 전체 평균, 단위/등급 분리, 기간 경계, 빈 결과를 검사합니다.
PHP 문법 검사도 통과했습니다.

모든 필터 조합을 전수 검사한 것은 아닙니다. 새 XAMPP 설치·덤프 복원·최종 공통 UI 통합 검증은
팀의 최종 통합 테스트에서 별도로 수행합니다.

### 공유 파일

- `team01/analysis/rollup.php`: 조회 화면과 계층 이동
- `team01/includes/rollup.php`: 입력 검증, 허용 목록 기반 SQL 생성, URL 생성
- `team01/assets/css/rollup.css`: 화면 전용 스타일
- `team01/index.php`: 기존 메뉴에 Rollup 링크 연결
- `scripts/check-rollup.php`: CLI 회귀 검사
- `documents/rollup.md`: 사용법과 검증 기록

개인 DB 설정, 원본 CSV, 로컬 DB 갱신용 SQL은 이 기능의 공유 대상에 포함하지 않습니다.
