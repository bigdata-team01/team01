# 가격 등록·수정 로그인 연결

- 로그인·회원가입·로그아웃 파일은 유채은 작성 코드입니다. `chaeeun` 브랜치의 `e12b349b1cab64e6487d54db759fab335b103cc9` 버전에서 내용 변경 없이 가져왔습니다.
- 이혜령의 `includes/require_price_login.php`가 채은님 코드의 `$_SESSION['user_id']`를 확인합니다. 등록·수정·수정 대상 목록에서 DB 처리 전에 실행합니다.
- 로그인하지 않은 GET/POST 요청은 로그인 화면으로 이동합니다. 로그인 성공 후 기존 동작대로 메인 화면으로 이동하며, 메인의 가격 관리 링크를 사용합니다. 로그인 전에 작성한 POST를 자동 재전송하지 않습니다.
- 현재 APP_USER에 권한 구분이 없으므로 모든 로그인 회원이 가격을 등록·수정할 수 있습니다.
- 시험: 비로그인 GET/POST 차단, 회원가입, 잘못된 비밀번호, 로그인, INSERT/UPDATE 성공 및 오류 처리, 로그아웃 후 차단을 로컬 테스트 DB에서 확인했습니다. 임시 회원과 가격은 정리했습니다.
- 팀 통합 시 채은님 인증 코드의 최신 변경을 확인하고 세션 키를 일치시켜야 합니다. 개인 DB 연결 설정인 `config/local.php`는 Git에 포함하지 않습니다.
